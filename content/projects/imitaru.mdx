## The Pitch & The Core Problem

Traditional online learning has a catastrophic **96% dropout rate**. For neurodivergent minds (ADHD, focus challenges) and learners in low-bandwidth or underserved communities, long 60-minute video lectures and passive multiple-choice quizzes cause immediate cognitive fatigue and abandonment. Learners get trapped in "tutorial purgatory" with zero accountability, no real-time peer feedback, and no immediate reinforcement.

**Imitaru** flips this paradigm from the ground up. Co-founded alongside **Nuno Ribeiro**, Imitaru is a decentralized, peer-powered micro-learning and earning platform engineered around three psychological and systems principles:

1. **Mirror Neuron Activation & Co-Working Pods**: Small, intimate cohorts (5–12 learners) led by vetted mentors for synchronous accountability, collaborative pair sprints, and body doubling.
2. **Hyper-Focused Loopbacks**: Strict 30–90 second bite-sized video capsules capturing real progress (*"Today I learned..."*, *"I built..."*, *"I solved..."*), eliminating blank-page paralysis.
3. **The Origami Micro-Coin Economy**: An instant 1-tap appreciation ledger where supporters lift creators with micro-coins, backed by a reversible 30-second escrow countdown and animated origami cranes.

The system is fully documented in our living [IEEE 830-1998 Software Requirements Specification (SRS)](https://docs.google.com/document/d/1S2ISijhsRTA9r_O4AhdM-sarbSbocIFpblaKqRCn3hY/edit) and shipped in production at [imitaru.com](https://www.imitaru.com/).

## Core Architectural Pillars

### 1. The Loopback Creation Pipeline (SRS §3.2.4)
To prevent ADHD cognitive paralysis, content creation is bound by strict technical constraints:
- **Duration Enforcement**: Hard ceiling of 30 to 90 seconds.
- **Client-Side Media Processing**: Video capture uses the browser's native `MediaRecorder` API with client-side canvas trimming and audio normalization. This offloads expensive video re-encoding from cloud servers and preserves bandwidth for users in underserved regions.
- **Scaffolded Titling**: Eliminates the "empty input" block by automatically injecting structured prompt templates:
  - *"Today I learned..."*
  - *"I built..."*
  - *"I solved..."*

### 2. The Reversible 30-Second Origami Appreciation Ledger (SRS §3.2.6)
Imitaru replaces generic "likes" with a tangible micro-coin economy:
- **1-Tap Appreciation**: Tapping "Appreciate" transfers 1 coin from the supporter's wallet to the creator.
- **30-Second Reversible Escrow**: People with ADHD frequently experience accidental or impulsive tapping. Imitaru solves this with a **30-second client-side countdown timer**: during the countdown, tapping again instantly cancels the transfer ("un-tap") with zero server friction.
- **Atomic Settlement**: Once the 30-second timer elapses, an idempotent background mutation executes a Prisma transaction:
  ```typescript
  // Atomic settlement transaction
  await prisma.$transaction([
    prisma.wallet.update({
      where: { userId: supporterId },
      data: { balance: { decrement: 1 } },
    }),
    prisma.wallet.update({
      where: { userId: creatorId },
      data: { balance: { increment: 1 } },
    }),
    prisma.coinTransaction.create({
      data: {
        senderId: supporterId,
        receiverId: creatorId,
        loopbackId: loopbackId,
        amount: 1,
        status: "CONFIRMED",
      },
    }),
  ]);
  ```
- **Visual Feedback**: Triggered appreciation launches a custom animated fluttering origami crane, while unlocking community builder badges and global reach indicators (*"Appreciated in +12 countries"*).

### 3. Discovery Feed & Cold-Start Matching (SRS §3.2.3 & §3.2.5)
- **Interest Graph Weighting**: During onboarding, users select 5 core skill interests and auto-follow 3 trending mentors. The feed engine calculates a weighted relevance score factoring tag intersection, mentor affinity, and exponential recency decay.
- **Guest Teaser Experience**: Guests can explore top loopbacks with autoplay. However, appreciation counters, coins, and follower metrics are blurred with an internationalized teaser: *"Unlock your appreciation and earn your wings. Join Imitaru now."*

### 4. Live Mentor Pods & 3-Tier Monitization Model (SRS §3.2.1)
- **Synchronous Micro-Cohorts**: Pods connect small groups (5–12 learners) with verified senior mentors over WebRTC for structured exercises, real-time code reviews, and live Q&As.
- **Pricing Tiers**:
  - **Basic ($0/Free)**: Access to free community pods, discussion threads, and badge progression.
  - **Premium ($29/month)**: Access to premium mentor pods, exclusive workshops, and 1-on-1 consultations.
  - **Pro ($59/month)**: Priority booking for mentors, discounted consultation packages, and early feature access.

## Technical Decisions & Engineering Trade-Offs

| Decision | Alternative Considered | Why Imitaru Chose It |
|---|---|---|
| **Jotai Atomic State** | Redux Toolkit / Zustand | Bounded atomic atoms isolate re-renders. High-speed video scrubbing, coin countdown timers, and WebRTC participant lists update independently without re-rendering the entire feed hierarchy. |
| **Prisma + PostgreSQL (Supabase)** | MongoDB / DynamoDB | Financial ledgers, reversible escrow countdowns, and 4-state RBAC require strict ACID transactional guarantees that NoSQL cannot reliably provide. |
| **In-Browser Media Trimming** | AWS MediaConvert Server Transcoding | Trimming 30–90s clips directly in the client via Canvas/WebCodecs slashes infrastructure costs to near zero and prevents high server egress bills. |
| **4-State RBAC Model** | Binary Role Checks (`admin`/`user`) | Granular entity-level permission matrix (`Denied`, `List`, `Read`, `Write`) mapped directly to DB entities allows communities, pods, and private drafts to share unified API endpoints. |
| **Self-Hosted PostHog** | Google Analytics / Mixpanel | Protects learner privacy under GDPR and eliminates third-party tracking dependencies for international and European learner bases. |

## Key Metrics & Production Reality

- **Target Response Time**: `<2s` across 95% of operations (achieving ~320ms on Next.js Edge handlers).
- **Concurrency Target**: Engineered for 10,000 concurrent learners with pooled database connections.
- **Content Constraint**: 30–90 seconds per Loopback — optimized for ADHD working memory retention.
