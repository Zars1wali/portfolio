## 🌟 Overview

A modern, high-performance personal developer portfolio showcasing software engineering, cybersecurity research, and agentic AI systems. Built with **Next.js App Router**, featuring custom **Three.js** canvas interactions, fluid **GSAP** timeline animations, and a responsive **Tailwind CSS** design system.

## 🚀 Getting Started

First, install the dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## 🛠️ Complete Technology Stack

- **Core Framework:** [Next.js](https://nextjs.org/) (App Router, Server & Client Components)
- **UI & Components:** [React](https://react.dev/), [Lucide React](https://lucide.dev/)
- **Visuals & 3D:** [Three.js](https://threejs.org/), [GSAP](https://gsap.com/) Animations
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) & PostCSS
- **Language:** [TypeScript](https://www.typescriptlang.org/) (Strict type checking)
- **Deployment & Analytics:** [Vercel](https://vercel.com/)
